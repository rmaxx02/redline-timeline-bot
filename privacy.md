# Redline Timeline Bot — Privacy Policy

This Discord bot collects and stores the following data solely to operate its features: Discord user IDs, usernames, and clip-submission counts (for the leaderboard/rank system). It does not collect passwords, payment information, or any data beyond what Discord's API provides.

Data is stored only for as long as the bot is active in the server and is not sold, shared, or used for advertising.

The bot also queries the public YouTube Data API to check for public video/live-stream metadata from specific YouTube channels — no personal YouTube account data is accessed.

Users may request their data be removed by contacting server staff.
